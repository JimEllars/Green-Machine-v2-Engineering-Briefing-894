# Future Enhancements

This document tracks the backlog for continuous development and upcoming sprint targets.

## Upcoming Sprint Targets

* **AXiM Internal SSO Integration:** Implement internal single sign-on (SSO) to streamline user authentication across AXiM services.
* **Advanced Charting UI for Market Feed:** Enhance the Market Feed matrix with advanced interactive charting capabilities for better data visualization and analysis.
* **Multi-Exchange API Support:** Extend the platform's trading capabilities by integrating with multiple cryptocurrency exchanges, reducing reliance on a single provider and enabling cross-exchange arbitrage opportunities.
